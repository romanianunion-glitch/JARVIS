# JARVIS

Cross-platform personal AI assistant.

## Architecture

- core/: Shared configuration
- platforms/windows/: Windows-specific implementation
- platforms/linux/: Linux-specific implementation
- pwa/: Progressive Web App
- docker/: Container configuration
- docs/: Documentation

## Platforms

- Windows 11 — see [Windows installation guide](docs/WINDOWS-INSTALLATION.md).
- Arch Linux / CachyOS — see [CachyOS installation guide](docs/CACHYOS-INSTALLATION.md).
